## 🧮 Mathematical Scoring Standard

Typing metrics follow standard touch-typing scoring conventions:

$$\text{Raw WPM} = \frac{\text{Total Keystrokes} / 5}{\text{Time in Minutes}}$$

$$\text{Net WPM} = \max\left(0, \, \frac{(\text{Correct Keystrokes} / 5) - \text{Uncorrected Errors}}{\text{Time in Minutes}}\right)$$

$$\text{Accuracy (\%)} = \left( \frac{\text{Correct Keystrokes}}{\text{Total Typed Keystrokes}} \right) \times 100$$

$$\text{Consistency (\%)} = \max\left(0, \, 100 - (\sigma_{\text{keystroke interval}} \times 20)\right)$$
